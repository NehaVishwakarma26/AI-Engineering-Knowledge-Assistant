A vector database is a specialized storage system designed to handle high-dimensional vector data, commonly referred to as embeddings. Unlike traditional relational databases that query based on exact keyword matches, vector databases retrieve data using Approximate Nearest Neighbor (ANN) algorithms. Common algorithms include Hierarchical Navigable Small World (HNSW) graphs and Inverted File Index (IVF). When a query vector is submitted, the database calculates distances using metrics such as Cosine Similarity, Euclidean Distance (L2), or Dot Product. This allows AI systems to find semantically similar concepts even if the exact keywords do not match, which is the foundational retrieval mechanism for semantic search and RAG pipelines.
